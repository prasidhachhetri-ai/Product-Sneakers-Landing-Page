# Sneakers Nepal Product Landing Page

A responsive Air Jordan 4 landing page and Cash on Delivery ordering flow built with Next.js, TypeScript, and Tailwind CSS.

## Features

- Responsive design for desktop, tablet, and mobile
- Complete Air Jordan 4 colorway gallery
- Mixed-color cart with size and quantity controls for every selected pair
- Delivery-area selection with automatic totals
- Checkout with matching selected product imagery
- Google Sheets order storage
- Business and customer email confirmations
- Branded thank-you page

## Local setup

1. Run `npm install`.
2. Copy `.env.example` to `.env.local` and enter your own credentials.
3. Run `npm run dev`.
4. Open `http://localhost:3000`.

Keep service-account keys, application passwords, and `.env.local` private. Never commit real credentials to Git.
